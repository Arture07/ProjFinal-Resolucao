# Missão Galáctica — Estação Espacial Órbita-7

## Pré-requisitos
- Java (JDK) instalado.

## Como rodar

1. Abra o terminal na pasta do projeto.
2. Compile os arquivos Java:

```powershell
javac -encoding UTF-8 *.java
```

3. Execute o programa:

```powershell
java Main
```

> **Obs.:** Mantenha o arquivo `tripulantes.txt` na mesma pasta em que você executar o comando `java Main`, pois o programa lê os dados iniciais dele ao iniciar.
